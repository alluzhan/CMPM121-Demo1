# Pumpkin Clicker

Pumpkin Clicker is a incremental game that grows a pumpkin to get more seeds.

Play Link: [Pumpkin Clicker](https://alluzhan.github.io/CMPM121-Demo1/)

## How To Play:

1. Click on the pumpkin to generate seeds
2. Use the seeds to buy upgrades: water, sunshine, fetilizer, or a farm. Each upgrade increases the seed rate per second growth.
3. As the seed rate per second rises the pumpkin will grow bigger
